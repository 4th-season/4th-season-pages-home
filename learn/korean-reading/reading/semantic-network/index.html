문해력 국어 · 새 시리즈

의미망으로 읽는 글의 구조

수능 기출 독서를 중심으로

단어 하나의 뜻을 아는 것에서 멈추지 않고, 단어와 문장이 서로 어떻게 연결되는지를 따라가며 문단과 글 전체의 구조를 읽는 연재입니다. 실제 수능·평가원 독서 지문을 통해 읽기의 과정을 단계별로 익힙니다.

왜 ‘의미의 연결’을 먼저 보는가

글은 문장들의 단순한 모음이 아닙니다. 앞에서 나온 대상이 뒤 문장에서 다시 설명되기도 하고, 하나의 원인이 다음 결과를 만들기도 하며, 두 견해가 같은 기준에서 비교되거나 서로 반박되기도 합니다. 독해는 이런 연결을 놓치지 않는 일에서 시작합니다.

이 시리즈는 먼저 단어와 문장 안의 연결을 정확히 읽고, 그 위에서 문단의 역할과 글 전체의 전개를 이해하도록 구성합니다. ‘이 문단은 비교다’처럼 이름부터 외우기보다, 실제로 무엇과 무엇이 어떤 관계로 이어지는지를 확인한 뒤 글의 구조를 정리합니다.

시리즈의 읽기 순서

단어의 뜻→문장 안의 연결→사건과 조건→문장 사이의 관계→문단의 중심과 기능→글 전체 구조→수능 선지 판단
각 글은 이론 설명으로 끝나지 않습니다. 필요한 경우 실제 평가원 지문을 읽고, 그 지문에서 같은 원리가 어떻게 작동하는지 확인합니다.

3. 혼자 다시 읽어 봅니다짧은 적용 문제와 해설을 통해 같은 읽기 원리를 스스로 사용할 수 있는지 점검합니다.
자료 기준
이 시리즈는 국립국어원의 한국어 구조 분석 관련 연구와 말뭉치의 분석 관점을 참고하고, 실제 적용에는 한국교육과정평가원의 수능·모의평가 국어 영역 독서 지문을 사용합니다. 각 글의 출처는 해당 글에 별도로 표시합니다.
